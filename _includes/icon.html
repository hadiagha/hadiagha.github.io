{% comment %} Icons, inlined as SVG. {% include icon.html name="github" %} {% include icon.html name="rss" label="RSS feed" %} Pass `label` when the icon is the only content of its link or button, so it has an accessible name. Leave it off and the icon is marked aria-hidden, which is correct whenever adjacent text already says what it means — an icon that is neither labelled nor hidden gets announced as a meaningless graphic. These replace the Font Awesome stylesheet, which cost 102 KB plus a connection to cdnjs.cloudflare.com on every page in order to draw about thirty glyphs. The outlines here are Font Awesome's own, taken from version 6.4.0 — the version that stylesheet pinned — so nothing about the site's appearance changes. Two names resolve differently from how they are written at the call site, because Font Awesome 6 renamed them and kept the old spelling as an alias: `edit` is pen-to-square, `file-alt` is file-lines, `square-root-alt` is square-root-variable, `sticky-note` is note-sticky, `times` is xmark, and `university` is building-columns. The site was already getting the new glyphs; this just makes it explicit. `x-twitter` is the exception that was NOT already working: it did not ship until 6.4.2, so under the pinned 6.4.0 stylesheet the X icon in the footer and on the contact page rendered as nothing at all. It is included here, which fixes it.
