{% comment %} Inline SVG icons. {% include icon.html name="github" label="GitHub" %} {% include icon.html name="arrow-right" %} `label` makes the icon an image with an accessible name — use it when the icon IS the link, as in the footer's social row. Omit it and the icon is marked aria-hidden, which is right whenever adjacent text already says what it means. An icon that is neither labelled nor hidden gets announced by screen readers as a meaningless graphic, so there is no third option. This replaces the Font Awesome stylesheet, which cost 102 KB plus a third-party connection to render about thirty glyphs. Ten of those turned out to be decoration next to text that already said the same thing, and were dropped rather than converted.
