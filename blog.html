--- permalink: /blog/ sitemap: false redirect_to: /writing/ --- {%- comment -%} The post index moved from /blog/ to /writing/. This page keeps the old address working. Individual posts did NOT move: their permalink is still /blog/:year/:month/:day/:title/ and it must stay that way, because the URL of a published post is a promise. Only this index changed, so only this one address needs a redirect. GitHub Pages serves static files and cannot issue a 301, so this is the standard meta-refresh stand-in. The canonical link is what tells search engines which of the two addresses is the real one — without it they index both and split the ranking. `sitemap: false` keeps jekyll-sitemap from listing a page whose only job is to leave. Anyone with JavaScript gets there a beat sooner via location.replace, which also keeps the redirect out of the back-button history. {%- endcomment -%} Redirecting to Writing
