--- layout: page title: Search description: Everything on this site, indexed permalink: /search/ search: false sitemap: false --- {% comment %} Pagefind. The index is built from the generated HTML after Jekyll runs — see the `search` target in the Makefile and the build step in both workflows — so it is served from this origin like everything else. There is no search API and no third party: what someone types here never leaves their browser. This uses Pagefind's Component UI (the custom elements below) rather than the older PagefindUI class. Pagefind's own advice for new integrations as of 1.5.0, and the reason given is accessibility, which is worth the larger bundle on a page nobody loads unless they want to search. The index does not exist during `make preview`, because `jekyll serve` never writes the _site directory Pagefind reads. Hence the fallback at the bottom: an empty box that silently does nothing is worse than a sentence saying why. {% endcomment %}
